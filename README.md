# Iris: a casa

Modelo da **casa da Iris**, a assistente pessoal que funciona só pelo celular, dentro do app do Claude (aba Code).
Cada pessoa cria a sua cópia **privada** deste modelo: é onde a Iris guarda a memória e os arquivos dela.

**Para instalar, abra no celular:** https://cristianodacunha.github.io/iris-casa/

O jeito de trabalhar da Iris (o cérebro) vem do suporte da Iris a cada conversa e depende de um acesso ativo.
Este modelo não tem nenhum dado pessoal, e a Iris nunca pede senha, código ou chave.
