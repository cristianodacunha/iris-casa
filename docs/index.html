Instalar a IrisPasso 1 de 6

Oi! Vamos ligar a Iris no seu celular 💜

Ela vai morar dentro do app de inteligência artificial que você já usa. Qual é o seu?

Leva uns 10 minutos. Se você sair desta página, ela lembra onde parou.

Primeiro, o cofre da Iris

A Iris guarda a memória e os seus arquivos no GitHub, num lugar privado que só você vê.

Criar minha conta no GitHub Já tenho conta: entrar

O GitHub manda um código para o seu e-mail para confirmar. Guarde bem a senha: a Iris nunca vai pedir.

No iPhone: quando terminar, volte para esta aba do Safari (ícone de abas, no canto).

Agora, crie a casa da sua Iris

O botão abre a tela do GitHub já preenchida. Lá você só:

  1. Confere se está marcado Private.
  2. Toca em Create repository, no fim da tela.
Criar a casa da minha Iris

Se o GitHub disser que o nome já existe, é porque você já criou antes. Pode seguir.

Se abrir o app do GitHub e não aparecer a tela de criar, toque e segure o botão roxo e escolha Abrir em Nova Aba.

Peça o seu código de ativação

É ele que liga a sua Iris. Toque no botão para pedir a quem te passou a Iris.

Pedir o código pelo WhatsApp

O código começa com IRIS-. Guarde a mensagem: na primeira conversa, a Iris vai pedir, e é só copiar e colar.

Ligue o Claude no cofre

Só desta vez, pelo navegador:

  1. Toque no botão e entre com a sua conta do Claude.
  2. Toque em Conectar ao GitHub (Connect GitHub) e autorize.
  3. No GitHub, escolha Only select repositories, marque minha-iris e confirme.
Abrir o Claude Code

Ligue o ChatGPT no cofre em teste

Só desta vez, pelo navegador:

  1. Toque no botão e entre com a sua conta do ChatGPT.
  2. Toque em Conectar ao GitHub e autorize, escolhendo minha-iris.
  3. Crie um ambiente (environment) para minha-iris. Em Script de configuração (Setup script), cole a linha abaixo e salve.
bash iniciar.sh Abrir o Codex

Diga oi para a Iris

  1. Abra o app do Claude.
  2. Toque na aba Code.
  3. Escolha minha-iris e escreva "Oi, Iris".
Abrir o Claude

É sempre por ali: aba Code, minha-iris. A Iris lembra de tudo de uma conversa para a outra.

Diga oi para a Iris

  1. Abra o app do ChatGPT e entre no Codex.
  2. Escolha minha-iris e escreva "Oi, Iris".
  3. No fim de cada conversa, toque em Criar PR (Create PR). É assim que a Iris guarda o que aprendeu.
Abrir o ChatGPT
🎉

A Iris é sua!

Peça do jeito que você fala: "monta uma planilha dos meus gastos", "me lembra de pagar a luz dia 5", "prepara minha consulta de quinta".

Os arquivos que ela criar chegam com um link para baixar. Os lembretes vão direto para a agenda do celular.
